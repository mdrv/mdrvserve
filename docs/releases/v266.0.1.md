## v266.0.1 — Cross-platform binaries (macOS, Windows, ARMv7)

Expands release binary coverage from four Linux targets to eight targets
spanning Linux, macOS, and Windows.

### Added

- **macOS binaries** (`x86_64-apple-darwin`, `aarch64-apple-darwin`).
- **Windows binary** (`x86_64-pc-windows-msvc`).
- **ARMv7 Linux binary** (`armv7-unknown-linux-musleabihf`) for Raspberry Pi 2/3
  in 32-bit mode.
- **`install.sh` macOS support.** The installer now detects Darwin and maps to the
  correct Apple binary.

### Changed

- **README installation section** simplified: single `install.sh` curl command
  covers Linux and macOS. Homebrew instructions removed.
- **Release workflow** updated: cross-compilation for ARMv7 via
  `gcc-arm-linux-gnueabihf`, Windows builds on `windows-latest`, macOS builds on
  `macos-latest`.

### Install

```bash
# Linux or macOS — detects platform
curl -sSfL https://raw.githubusercontent.com/mdrv/mdrvserve/main/install.sh | bash

# From source
git clone https://github.com/mdrv/mdrvserve.git
cd mdrvserve && cargo build --release
```

Or download a binary from the
[latest release](https://github.com/mdrv/mdrvserve/releases/latest).
